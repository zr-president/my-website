# AI行业日报 — 2026年9月12日

## 今日焦点：DeepSeek V4.1 Flash 发布——开源模型追平闭源旗舰

9月10日，DeepSeek 发布 **V4.1 Flash**——新架构家族中最小、最智能的模型，且**原生支持视觉理解**。真正值得注意的是：它在多个 benchmark 上**超过 Claude Opus 5 与 GPT-5.6 Sol**，而且是 MIT 开源。

## 核心信息

### 规格
- **5520 亿参数 MoE**（激活：输入 80 亿 / 输出 160 亿）
- **原生视觉理解**——支持图像输入（不再是纯文本）
- 新预训练 + 强化学习方法（与 V4 不同）

### 性能（第三方评测）
| 评测 | 结果 |
|------|------|
| 多个 benchmark | **超过 Claude Opus 5 与 GPT-5.6 Sol** |
| AutomationBench-AA（事务/财务/人事 Agent） | **超 GPT-6 Astra，拿下第一** |
| Artificial Analysis 智能指数 v4.3 | 40 分（超 GPT-5.6 Luna） |
| 输出速度 | 仅次于 Gemini 3.8 Flash / Muse Spark 1.3 |
| 任务输出 token | 偏多（比 Claude Fable 5.1 多） |

### 成本
- **KV 缓存 token 降至 V4-Flash 的 1/3.9**，显存 1/4、存储 1/8
- API：峰值输入 **$0.3**、缓存输入 **$0.006**、输出 **$1.2**（非峰值**半价**）
- **MIT 开源**，HuggingFace / ModelScope 可下载本地部署

## 同期动态

### Agent 成主战场
- **OpenAI 推出 Agents API 公开测试版**——Agent 开发走向标准化
- **无问芯穹 × 基元律动发布 NeoHorse**——行业首个 Agent-Native 模型
- V4.1 Flash 在 AutomationBench-AA（事务性 Agent）拿第一

### AI 治理立法化
- **美国加州签署 AI 安全法案**（获 Anthropic、OpenAI 支持）——AI 安全从企业自律走向立法

### 国内政策
- **工信部《人工智能+软件专项行动实施方案》**：到 2028 年累计 100 项软件企业智能化技改项目，部署智能编程与算力协同

## 趋势判断
1. **开源追平闭源**——"开源=能力弱"的认知被进一步打破
2. **Agent 是竞争核心**——API 标准化 + Agent-Native 模型 + 新评测维度
3. **AI 安全立法化**——安全/治理/合规从话题变成要求
4. **成本持续下降**——KV 缓存优化 + API 降价 → Agent/大规模推理门槛降低

## 对你的启示
1. **立刻升级工具链**：Harness + V4.1 Flash 替代 V4-Flash（性能+视觉+成本三赢）
2. **多模态落地**：原生视觉→可分析网站截图/海报/穿搭图
3. **写行业观察**：《开源追平闭源意味着什么》——当下最有信息量的话题
