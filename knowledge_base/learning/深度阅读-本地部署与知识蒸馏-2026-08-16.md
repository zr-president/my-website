# 深度阅读 · AI本地部署 与 知识蒸馏（2026-08-16）

## 核心：三个容易混淆的概念

| 概念 | 类比 | 说明 |
|---|---|---|
| 大模型本身（DeepSeek V4 / Qwen3.8） | 发动机 | 负责思考/生成 |
| Agent 框架（Harness / Claude Code / Codex） | 驾驶舱+司机 | 负责拆任务/改文件/调工具，不包含模型 |
| 部署方式（本地 / API / 混合） | 自己发电 vs 电网买电 | 模型跑在哪 |

**关键认知**：Harness 与本地部署是不同维度——Harness 是工具（驾驶舱），本地部署是能源选择（发电机放哪），两者可以组合。

## 一、本地部署 vs API

| 维度 | 本地部署 | API（现状） |
|---|---|---|
| 隐私 | ✅ 数据不出电脑 | ⚠️ 经过厂商服务器 |
| 成本 | 一次性硬件+电费（长期趋近0） | 按量付费（DeepSeek 8/17涨价后高峰¥27/百万tokens） |
| 联网 | ✅ 断网可用 | ❌ 必须联网 |
| 能力 | ❌ 受显卡限制（只能跑小模型） | ✅ 旗舰模型随便用 |
| 速度 | ⚠️ 家用电脑慢 | ✅ 云端GPU快 |
| 维护 | 自己装环境/调显存 | 零维护 |

**硬件门槛**：270亿参数 Qwen3.8-27B 量化后约 16-20GB 显存（RTX 4090 级别）；普通 8GB 显存笔记本只能跑 7-14B 小模型。

## 二、本地部署适用场景

✅ 适合：①隐私敏感（简历/体检/财务材料）②高频重复低成本（网站维护/批量格式化，躲开涨价）③离线使用 ④学习定制（随便折腾微调，求职加分）

❌ 不适合：①复杂推理/长文写作（小模型写不动）②需要最新知识（知识停在训练截止日）③多模态/长上下文

> 一句话：本地部署买的是【隐私+省钱+可控】，卖的是【能力+新鲜度】。

## 三、小模型是大模型"训练"出来的吗？——是的，叫知识蒸馏

**老师-学生机制（2015 Hinton 提出）**：
1. 大模型（老师）生成海量问题+答案+「答题思路」（软标签/概率分布）
2. 小模型（学生）模仿老师的答案和思路反复练习
3. 学生达到老师 80-90% 能力，体积仅 1%

**关键**：老师教的不仅是答案，还有「模糊地带的倾向」——这让小模型学得远比死记硬背快。DeepSeek-R1、Qwen 小尺寸版本基本都是蒸馏产物。

**两个真相**：①蒸馏不是唯一方式（也有从头训练，但成本高）②学生有天花板——老师不会的，学生永远学不到。

## 四、小模型 vs 大模型

| 维度 | 大模型（Qwen3.8-Max·2.4T） | 小模型（Qwen3.8-27B） |
|---|---|---|
| 参数 | 2.4万亿（MoE激活950亿） | 270亿（1/90） |
| 知识广度 | 海量+深度推理 | 常见任务够用，冷门露怯 |
| 推理深度 | 多步逻辑/数学/代码严谨 | 复杂推理易出错 |
| 幻觉率 | 低 | 更高（不懂装懂） |
| 成本/速度 | 贵、慢（云端） | 便宜、快（家用可跑） |
| 运行环境 | 只能云端 | 自己的电脑 |

## 五、模型选型=面试高频题（答题模板）

> 核心公式：**用户价值（效果）÷ 成本（算力）**
> 蒸馏让「1% 成本获得 80% 效果」成为可能，所有主流厂商都在推小模型。
> 答：什么时候用大模型（复杂任务/容错低）、什么时候小模型够用（高频简单/成本敏感）、蒸馏的代价（能力天花板）。

## 六、实操建议（钟锐）

1. 先看显卡显存（任务管理器→性能→GPU），≥16GB 再考虑 27B；8GB 先玩 7B 体验
2. 值得本地部署的场景：求职简历/面试材料等隐私数据（数据不出域最安全）
3. 别指望本地替代 Harness——Harness 是继续要用的驾驶舱，本地部署只是换更便宜的发动机
4. 最快体验路径：装 Ollama → `ollama run qwen3:8b` → 让 Harness API 地址指向本地
