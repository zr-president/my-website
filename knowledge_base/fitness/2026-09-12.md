# 健身 · 8周腹肌专项计划 — 2026年9月12日

## 你的情况诊断
- **身体数据**：170cm / 59kg（BMI ≈ 20.4，偏瘦）
- **现状**：能摸出腹肌轮廓，但肚子上仍有赘肉 → 典型 **skinny fat（瘦胖子）**，体脂率约 **15-18%**
- **基础**：俯卧撑一口气 **60 个**（优秀）、平板支撑 **2分半**（很强）→ 可直接上强度
- **目标**：腹肌线条可见

## 核心判断（三个真相）
1. **腹肌是"厨房里练出来的"**——可见度由体脂率决定（男性需 ≤12-15%），练腹只能让腹肌变厚，**不能消掉覆盖它的脂肪**
2. **瘦子不能靠饿**——59kg 已偏瘦，大减重会掉肌肉，变成"更瘦但更松"；正确做法是**控脂 + 增肌同步**（腹肌厚度 + 背部宽度）
3. **局部减脂不存在**——不能"只减肚子"，要靠跳绳等全身有氧整体降体脂

## 每周训练结构
| 星期 | 内容 |
|------|------|
| 周一 | 跳绳HIIT + 腹肌专项A |
| 周二 | 俯卧撑变式（胸/三头）+ 拉力绳背 |
| 周三 | 休息 / 快走30min |
| 周四 | 跳绳HIIT + 腹肌专项B |
| 周五 | 拉力绳全身 + 平板支撑变式 |
| 周六 | 有氧40min（跳绳/快走） |
| 周日 | 休息 + 拉伸/泡沫轴 |

## 跳绳（减脂主力·每周3-4次·15-20min）
- 初阶（1-2周）：30秒快跳 + 30秒休息 × 10组
- 进阶（3-5周）：40秒跳 + 20秒休息 × 12组
- 高阶（6-8周）：60秒跳 + 30秒休息 × 10组（穿插双摇）
- 燃脂效率：每小时约 600-1000 kcal

## 腹肌专项A（上腹+整体）
| 动作 | 组次 |
|------|------|
| 拉力绳跪姿卷腹 | 4×15 |
| 平板支撑变式（负重/单腿） | 3×90秒 |
| 仰卧抬腿 | 4×15 |
| 死虫式 | 3×12/侧 |

## 腹肌专项B（下腹+侧腹）
| 动作 | 组次 |
|------|------|
| 拉力绳伐木式 | 3×12/侧 |
| 侧平板支撑 | 3×45秒/侧 |
| 反向卷腹 | 4×15 |
| 俄罗斯转体 | 3×20 |

## 俯卧撑升级（60个已够·必须改变式）
宽距 4×20（胸外）｜钻石 4×12（三头）｜下斜 4×15（上胸）｜爆发/击掌 3×8-10

## 拉力绳（补背·让腹肌更显）
高位下拉 4×15（背阔）｜面拉 3×15（后肩/改善圆肩）｜坐姿划船 3×15｜站姿推举 3×12

## 饮食（决定成败·80%效果在这里）
- **热量**：2300-2500 kcal（轻缺口 ~200，**不要大开缺口**）
- **蛋白质**：106-130g/天（1.8-2.2g/kg）
- **碳水循环**：训练日 55%、休息日 40%
- **戒糖**：含糖饮料/夜宵/精制糖（最快见效，2周见腰围变化）
- **补水**：≥2.5L + 柠檬水（兼顾肾结石预防·控草酸）
- **睡眠**：7-8h（皮质醇高会让脂肪堆腹部）

## 监测与预期
- **每周量腰围**（不是体重）——腰围减少才是真减脂
- **每周拍正面照**（同光线姿势）
- **8周预期**：体脂降 2-4 个百分点、腹肌轮廓明显、腰围减 2-4cm
- **若4周无变化**：优先检查饮食（80% 概率是吃的问题）
